# CHAPS DBZ COLLECTION

Aplicación web instalable para organizar la colección de 169 Chaps Dragon Ball Z / GT.

## Incluye
- Catálogo visual de 169 referencias con sus fotografías numeradas (001–169).
- Filtros por serie Z/GT, álbum, Chipicao, «Las tengo» y «Me faltan».
- Marcado y desmarcado de cada chapa tocando su ficha.
- Búsqueda por número y progreso de colección.
- Temas visuales y control de animaciones.
- Conserva los datos en el almacenamiento local del navegador.

## Cómo usar
1. Descomprime la carpeta completa.
2. Abre `index.html` en un navegador para probarla.
3. Para publicar la aplicación en GitHub Pages, sube el contenido completo de esta carpeta a la raíz del repositorio. No subas solo el HTML: también debe estar la carpeta `assets/chaps`.

Las imágenes del catálogo se cargan desde `assets/chaps/NNN.jpg`.
